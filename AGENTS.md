# Разные люди — правила работы с проектом

Этот репозиторий содержит публичный сайт страйкбольной команды «Разные люди».

## Product goal
Главная цель сайта — привести заинтересованного человека от знакомства с командой к осознанному первому контакту. Любая новая страница должна помогать одному из маршрутов: команда → новичку → снаряжение/мероприятия → связь.

## Source of truth
- Визуальное наследие: commit `d62ae30249e5ca69e023a5429e9de537c69280c6`.
- Многостраничная архитектура до реконструкции: commit `5f5b51cc4990f9f78ee755e3d4cff52064946b23` и последующие.
- Оригинальная эмблема и реальные фотографии владельца имеют приоритет над генерацией.
- Не выдумывать даты, людей, достижения, правила, адреса, события и требования команды.

## Design
Тёмный лесной/графитовый фон, тёплый песочный акцент, крупная condensed editorial typography, full-bleed photography, асимметрия и negative space. Запрещено скатываться в SaaS/Tailwind-template эстетику, стеклянные карточки, бесконечные bento-grid и декоративные fake stats.

## Content
Публичный текст — прямой и предметный. Никаких developer notes, «здесь будет», «в дальнейшем», fake achievements или generic AI-copy. Если реального факта нет — скрыть блок либо отметить потребность только в документации.

## URLs
Канонические публичные разделы: `/`, `/team/`, `/start/`, `/gear/`, `/events/`, `/start/application.html`. Старые раздробленные URL сохранены только как noindex redirects.

## Engineering
Основной CSS: `css/site.css`. Основной JS: `js/site.js`. Не создавать каскад `*-fix.css`. При изменении layout обновлять эти файлы, а не добавлять временные патчи.

## Release gate
Перед merge: broken internal links 0, page errors 0, console errors 0, JS exceptions 0, horizontal overflow 0 на целевых viewports, public prototype phrases 0. Запустить Playwright QA и пройти `docs/RELEASE_CHECKLIST.md`.
