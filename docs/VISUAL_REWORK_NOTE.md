# Visual rework

The production branch keeps the multipage information architecture, QA, SEO and data separation, but the visual layer is anchored back to landing V1.

Key constraints for the current pass:
- cinematic dark forest composition;
- photography blended into scenes instead of card-first layouts;
- warm sand only as a restrained accent;
- editorial condensed typography without poster-scale overload;
- page-to-page continuity;
- no large flat sand CTA panels;
- no generic three-card rhythm as a default;
- internal pages must feel like chapters of the same visual story.
