# Landing V1 reference

Reference commit: `d62ae30249e5ca69e023a5429e9de537c69280c6`.

Старая версия используется как visual heritage, а не как готовая архитектура. Сохраняются: тёмная cinematic подача, крупные кадры, левое текстовое поле в hero, песочный акцент, вертикальный ритм, переходы между сценами и ощущение единой истории.

Не переносить обратно: одностраничную информационную перегрузку и привязку к системному Bahnschrift. Финальная версия использует multipage IA и web typography с кириллицей.
