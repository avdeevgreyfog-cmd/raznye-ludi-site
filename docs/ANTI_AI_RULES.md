# Anti-AI rules

Do not use by default: bento grids, glass cards, glow, acid gradients, giant rounded cards, pill labels, gradient buttons, fake statistics, decorative dashboards, repeated 3-column cards, meaningless 01/02/03 decoration, generic AI slogans.

A design element is allowed only if it supports hierarchy, navigation, comprehension or interaction.

Copy critic searches for: developer-facing phrases, placeholders, generic hype, repetitive sentence openings, fake certainty and unsupported facts.
