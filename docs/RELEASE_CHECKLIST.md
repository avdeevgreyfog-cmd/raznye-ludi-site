# Release checklist

- [ ] Core pages open at 360, 390, 768, 1024, 1440 and 1920 widths.
- [ ] Mobile navigation opens, closes and restores body scroll.
- [ ] No horizontal overflow.
- [ ] No console errors or uncaught JS exceptions.
- [ ] All primary internal links resolve.
- [ ] Recruitment form validates and produces an honest prepared-message state.
- [ ] No text claims that a message was sent when it was not.
- [ ] No public placeholder/developer copy.
- [ ] No unverified dates, people, achievements, addresses or team requirements.
- [ ] Titles/descriptions/canonicals are unique on canonical pages.
- [ ] Sitemap contains only canonical public pages.
- [ ] Redirect pages are noindex.
- [ ] Images have useful alt where semantic and empty alt where decorative.
- [ ] Keyboard focus is visible.
- [ ] `prefers-reduced-motion` is respected.
- [ ] CSS is consolidated in `css/site.css`; old patch styles removed.
- [ ] Temporary JS/components removed.
- [ ] Visual critic reports CRITICAL=0 and MAJOR=0.
