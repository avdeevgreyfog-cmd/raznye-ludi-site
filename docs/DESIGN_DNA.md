# Design DNA

## Character
- cinematic forest / graphite environment;
- warm sand accent;
- condensed editorial headings;
- documentary/tactical magazine tone;
- large photography integrated into composition;
- generous negative space;
- hard edges and thin borders instead of oversized rounded cards.

## Image language
Окружение: лесные полигоны, земля, трава, сосны, естественный свет. Экипировка в приглушённой природной палитре. В кадре важна рабочая ситуация, а не позирование.

## Composition library
Cinematic hero, split text/image, full-bleed scene, three-scene editorial sequence, timeline/list, manifesto rows, equipment breakdown, image strip, large CTA.

## Motion
Только reveal, subtle image motion and interaction feedback. Всегда учитывать `prefers-reduced-motion`.

## Anti-patterns
Glassmorphism, glow, acid gradients, generic SaaS cards, одинаковые 3-column grids на каждой странице, pill badges перед каждым заголовком, fake stats/counters, decorative dashboard UI.
