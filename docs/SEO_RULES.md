# SEO rules

Каждая каноническая публичная страница должна иметь unique title, description, single H1, canonical, OG title/image, semantic headings and useful internal links. Redirect/merged pages — `noindex`.

Sitemap содержит только канонические страницы с реальным публичным назначением. Не добавлять prototype/redirect URLs.

Search topics распределяются по intent: home — страйкбольная команда Москва; start — как попасть/первая тренировка; gear — снаряжение новичка; events — тренировки/игры.

No keyword stuffing. Text remains people-first. Structured data only when claim can be supported.
